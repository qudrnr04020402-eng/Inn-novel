# 은빛 여우관 PC 서버 — 폰에서 히로인과 자유 대화하기

내 PC에서 돌아가는 **로컬 LLM**(인공지능 모델)에게 히로인의 말투와 성격을 알려 주고, 안드로이드 폰 브라우저에서 히로인과 자유롭게 이야기(티키타카)하는 기능을 위한 서버입니다.
인터넷 서비스(ChatGPT 등)를 쓰지 않으며, 대화 내용은 내 PC 밖으로 나가지 않습니다.

```
[폰 브라우저] --(같은 와이파이)--> [PC: inn_server.py] --> [PC: Ollama 또는 LM Studio]
   게임 화면                     게임 파일 + 대화 중계          로컬 LLM (GPU)
```

> GitHub Pages 에 올린 게임 주소(https)에서는 이 기능을 쓸 수 없습니다. (https 페이지는 PC의 http 주소를 부를 수 없게 막혀 있어요.)
> 그래서 PC가 게임까지 직접 보내 주는 이 서버를 씁니다. 게임 자체는 서버 없이도 평소처럼 잘 돌아갑니다.

---

## 1단계. 로컬 LLM 준비 (Ollama 또는 LM Studio 중 하나)

### 방법 A. Ollama (명령어에 익숙하면 간단)

1. https://ollama.com 에서 Windows 용을 받아 설치합니다. 설치가 끝나면 작업 표시줄 오른쪽 아래에 라마 아이콘이 생기고 자동으로 서버가 켜집니다.
2. 명령 프롬프트(시작 메뉴에서 `cmd` 검색)를 열고 모델을 받습니다.
   ```
   ollama pull <모델이름>
   ```
   - 어떤 모델을 받을지는 **https://ollama.com/library 에서 최신 목록을 확인**하세요. 모델은 계속 새로 나옵니다.
   - **한국어가 되는 모델 계열**을 고르세요. 예: Qwen 계열, Gemma 계열 등. 이름 뒤의 `7b`, `9b` 같은 숫자는 모델 크기입니다.
   - **그래픽카드 VRAM에 맞는 크기**를 고르세요. 대략 **VRAM 8GB면 7~9B급(양자화된 것)**, 12GB면 12~14B급, 16GB 이상이면 더 큰 것도 가능합니다. 크기가 클수록 똑똑하지만 느리고 VRAM을 많이 씁니다.
   - 생각을 오래 하는 "추론/thinking" 모델보다 **일반 대화(instruct) 모델**이 이 게임에는 더 빠르고 잘 맞습니다. (게임 대사는 짧게 끝나야 해서 생각에 토큰을 쓰는 모델은 대답이 잘리거나 느려질 수 있어요.)
3. 잘 받아졌는지 확인합니다.
   ```
   ollama list
   ollama run <모델이름>
   ```
   `ollama run` 으로 한국어 인사를 해 보고 대답이 나오면 성공입니다. (`/bye` 로 나가기)

### 방법 B. LM Studio (그림 화면으로 쓰고 싶을 때)

1. https://lmstudio.ai 에서 설치합니다.
2. 왼쪽의 돋보기(Discover/검색) 탭에서 모델을 검색해 내려받습니다. 고르는 기준은 위 Ollama 설명과 같습니다(한국어 가능한 계열, VRAM에 맞는 크기).
3. **Developer 탭**(왼쪽 `<>` 아이콘)으로 이동 → 위쪽에서 받은 모델을 **불러오기(Load)** → **Local Server 를 Start(시작)** 합니다. 주소가 `http://127.0.0.1:1234` 로 표시되면 정상입니다.
4. 이때 서버는 이 PC 안에서만 열려 있으면 됩니다. (폰은 LM Studio 가 아니라 아래 `inn_server.py` 에 접속합니다.)

> **ComfyUI 와 동시에 쓸 때 주의**: 이미지 생성(ComfyUI)과 LLM 이 둘 다 그래픽카드 VRAM을 씁니다. 같이 켜 두면 VRAM이 모자라 둘 다 느려지거나 오류가 날 수 있어요.
> 게임을 하는 동안에는 ComfyUI 를 끄거나, 더 작은 모델(또는 더 강하게 양자화된 모델)을 쓰세요.

## 2단계. Python 설치 확인

1. 명령 프롬프트에서 아래를 입력합니다.
   ```
   python --version
   ```
   `Python 3.10` 이상의 숫자가 나오면 OK 입니다. (`py --version` 도 가능)
2. 없다면 https://www.python.org/downloads/ 에서 설치하세요. **설치 첫 화면 아래의 "Add python.exe to PATH" 를 꼭 체크**해야 합니다.
3. 추가로 설치할 패키지는 없습니다. (파이썬 기본 기능만 사용)

## 3단계. 서버 실행

1. 이 저장소 폴더의 `pc-server` 폴더를 엽니다.
2. **`start.bat` 을 더블클릭**합니다. 검은 창이 뜨고 아래처럼 나옵니다.
   ```
   폰에서 접속하세요 (같은 와이파이):
       http://192.168.0.12:8080
   LLM 연결 확인: OK  (모델 1개, 사용: ...)
   ```
3. 이 창을 **닫지 말고 그대로 두세요.** 닫으면 서버가 꺼집니다. 끝낼 때는 창을 닫거나 `Ctrl+C`.

### 설정을 바꾸고 싶다면 (선택)

`pc-server/config.json` 을 메모장으로 엽니다.

| 항목 | 의미 |
|---|---|
| `preset` | `ollama` 또는 `lmstudio`. 아래 `base_url` 이 비어 있을 때 쓰는 기본 주소 (Ollama `http://127.0.0.1:11434`, LM Studio `http://127.0.0.1:1234`) |
| `base_url` | LLM 서버 주소를 직접 적을 때 |
| `model` | 사용할 모델 이름. **비워 두면 자동 선택** (Ollama 는 `ollama list` 의 이름 그대로) |
| `port` | 게임 접속 포트 (기본 8080) |
| `timeout` | LLM 이 대답하기를 기다리는 최대 초 (기본 120) |

LM Studio 를 쓴다면 `"preset": "lmstudio"` 로 바꾸면 됩니다. 실행할 때 인자로 덮어쓸 수도 있어요.
```
start.bat --preset lmstudio
start.bat --model 모델이름 --port 8081
```

## 4단계. Windows 방화벽 허용

처음 실행할 때 **"Windows 보안 경고: Python 이 네트워크에 액세스하려 합니다"** 창이 뜹니다.

- **"개인 네트워크(집 또는 회사 등)"** 를 체크하고 **[액세스 허용]** 을 누르세요. (공용 네트워크는 체크하지 않아도 됩니다.)
- 창이 안 뜨거나 실수로 "취소"했다면: 시작 → "방화벽" 검색 → "Windows Defender 방화벽을 통해 앱 허용" → 설정 변경 → `python.exe` 를 찾아 "개인" 칸에 체크.

## 5단계. 폰에서 접속

1. 폰을 **PC와 같은 와이파이**에 연결합니다. (모바일 데이터 말고 와이파이, 게스트 와이파이 말고 같은 공유기)
2. 폰의 크롬에서 서버 창에 나온 주소(예: `http://192.168.0.12:8080`)를 입력합니다.
3. 게임을 시작하면 낮에 히로인과 시간을 보낸 뒤 **"조금 더 이야기해 볼까?"** 선택지가 나옵니다. 또는 메뉴 → **자유 대화** 로 그날 만난 사람과 대화할 수 있습니다.
4. 메뉴의 "자유 대화" 아래에 `PC 서버에서 실행할 때만 사용 가능` 이라고 보이면 서버 주소가 아닌 곳(GitHub Pages 등)에서 연 것입니다.

(팁) 크롬 메뉴의 "홈 화면에 추가"로 설치해 두면 편합니다. 다만 PC가 켜져 있고 서버가 실행 중일 때만 대화가 됩니다.

## 자유 대화 규칙 (밸런스)

- 한 히로인과 **하루 6번**까지 말할 수 있습니다. (다음 날 다시 6번)
- 자유 대화로 올릴 수 있는 호감도는 **히로인 한 명당 하루 +3, 모든 히로인 합쳐 하루 +4**까지입니다. 무례한 말로 깎이는 것은 하루 -4까지입니다. 그래서 대화만 계속해서 호감도를 올릴 수는 없고, 기존 엔딩 밸런스도 그대로입니다.
- 오류(연결 끊김 등)로 실패한 턴은 횟수에 세지 않습니다.
- 말투, 성격, 일차별 비밀 공개 범위, 위 숫자들은 `story/llm-persona.js` 에서 고칠 수 있습니다.

## 문제 해결

**폰에서 주소가 열리지 않아요 / 연결할 수 없다고 나와요**
- PC의 `start.bat` 창이 열려 있나요? 폰과 PC가 같은 와이파이인가요?
- 방화벽 허용(4단계)을 했나요? `Python` 항목이 "개인" 네트워크에서 허용돼 있어야 합니다.
- 서버 창에 나온 주소가 여러 개면 다른 것도 시도해 보세요. (가상 어댑터 주소는 안 될 수 있어요.) 직접 확인하려면 명령 프롬프트에서 `ipconfig` → 와이파이의 "IPv4 주소".
- 공유기의 "AP 격리"(기기 간 통신 차단)가 켜져 있으면 폰에서 PC로 접속이 안 됩니다. 공유기 설정에서 끄거나 다른 와이파이를 써 보세요.
- 포트가 이미 쓰이고 있다고 나오면 `start.bat --port 8081`.

**게임은 열리는데 "자유 대화"가 회색이에요**
- `PC 서버에서 실행할 때만 사용 가능` → 서버가 보내 준 주소로 접속했는지 확인하세요. (GitHub Pages 주소나 파일로 연 경우)
- `LLM 에 연결되지 않았어요` → PC에서 Ollama(작업 표시줄 아이콘이 있는지) 또는 LM Studio(Developer 탭에서 Local Server 가 Started 인지)를 확인하세요. 서버 창의 `LLM 연결 확인` 줄에도 같은 정보가 나옵니다. 켠 뒤 메뉴의 버튼을 다시 누르면 재확인합니다.
- LM Studio 는 **모델을 불러온(Load) 상태**여야 합니다. Ollama 는 `ollama list` 에 모델이 있어야 합니다.
- 모델을 직접 지정했다면 `config.json` 의 `model` 이름이 정확한지 확인하세요. (Ollama 는 `이름:태그` 형식, 예 `이름:7b`)

**대답이 이상해요 (영어가 섞이거나, 엉뚱하거나, 말투가 안 맞아요)**
- 작은 모델은 한국어 연기가 서툴 수 있습니다. 한국어를 잘하는 계열의 더 큰 모델을 써 보세요.
- 게임은 형식이 깨진 대답도 최대한 살려서 보여 주고, 영어로 답하면 한 번 다시 시킵니다. 그래도 이상하면 "다시 시도"를 누르세요.
- "생각(thinking)" 기능이 있는 모델은 생각이 길어 대답이 잘리거나 비는 일이 있어요. 일반 대화 모델을 쓰거나 생각 기능을 끄세요.
- 말투/성격을 바꾸고 싶다면 `story/llm-persona.js` 의 `speech`(말투 예시), `who`(성격)를 고쳐 보세요. 말투 예시를 더 넣으면 대체로 좋아집니다.

**너무 느려요**
- 첫 대답은 모델을 메모리에 올리느라 오래 걸릴 수 있어요(수십 초). 두 번째부터 빨라집니다.
- ComfyUI 등 다른 GPU 프로그램을 끄세요. VRAM이 모자라면 모델이 CPU 로 밀려나 매우 느려집니다. (Ollama: `ollama ps` 의 PROCESSOR 가 `100% GPU` 인지 확인)
- 더 작은 모델 또는 더 가벼운 양자화(Q4 등)를 쓰세요.
- 응답을 기다리는 시간이 부족하면 `config.json` 의 `timeout` 과 `story/llm-persona.js` 의 `settings.timeoutMs` 를 늘리세요.

**보안 참고**: 이 서버는 같은 와이파이의 기기라면 누구나 접속할 수 있습니다. 집 와이파이처럼 믿을 수 있는 네트워크에서만 쓰세요. LLM 쪽으로는 대화 내용(`/llm/chat`)만 중계하고, 모델 이름 등은 서버 설정만 사용합니다.

## 개발자용

| 파일 | 설명 |
|---|---|
| `inn_server.py` | 게임 서빙 + `/llm/chat` 중계 + `/llm/status`. 표준 라이브러리만 사용(Python 3.10+) |
| `start.bat` | 더블클릭 실행 (UTF-8 콘솔, `py` → `python` 순서로 찾음) |
| `config.json` | 기본 설정 |
| `fake_llm.py` | 테스트용 가짜 OpenAI 호환 LLM (정상/코드블록/잡문/깨진 JSON/지연/500 오류 등 시나리오) |
| `test_inn_server.py` | 서버 단위/통합 테스트: `python3 pc-server/test_inn_server.py` |

- 서버는 `index.html` 을 보낼 때 `<meta name="inn-server">` 를 끼워 넣습니다. 게임은 이 표식이 있을 때만 `/llm/status` 를 호출하므로, GitHub Pages 같은 정적 호스팅에서는 네트워크 오류 없이 자유 대화만 꺼집니다.
- `/llm/chat` 은 `messages, temperature, max_tokens, response_format, top_p` 만 LLM 으로 전달합니다. 스트리밍은 쓰지 않습니다(비스트리밍이 단순하고, 대사가 짧음).
- 직접 시험: 터미널 두 개에서 `python3 pc-server/fake_llm.py` / `python3 pc-server/inn_server.py --base-url http://127.0.0.1:11434` 후 `http://localhost:8080`. 대화창에 `#codeblock`, `#broken`, `#err500` 같은 태그를 넣으면 가짜 LLM 이 해당 시나리오로 답합니다 (`fake_llm.py` 맨 위 설명 참고).
- 통합 테스트: `node tools/test-llm.js` (Playwright), 파서/프롬프트 단위 테스트: `node tools/test-llm-core.js`.
